# PlanSeguro v4.0 · Rodolfo Valle

Actualización del sitio de orientación a cuidadores: incorpora un plan personal de seguridad editable e imprimible de seis pasos, adaptado del documento aportado por el usuario y de las recomendaciones de MINSAL (Anexo 4: Plan de seguridad).

## Instalación en GitHub Pages

1. Subir `index.html` a la raíz del repositorio `planseguro`, sustituyendo la versión anterior.
2. Mantener `CNAME` con `planseguro.rodolfovalle.com` para el dominio personalizado (si ese dominio ya está configurado).
3. Settings > Pages: verificar despliegue desde `main`, directorio raíz.
4. Abrir `https://planseguro.rodolfovalle.com/#plan-personal` para ir directamente al formulario.

No requiere dependencias, compilación, base de datos ni API externa. El formulario no usa localStorage, cookies, formularios enviados ni almacenamiento remoto. Los datos introducidos pueden aparecer en pantallas, impresiones o PDF creados por el usuario: manejar como datos sensibles.

## Seguridad de uso

La sección personal no es un instrumento de evaluación, ni sustituye la evaluación clínica, ni el SAMU 131, ni un protocolo clínico interno. La página no recoge identificadores ni información sobre los visitantes. Los teléfonos verificados corresponden a Chile y pueden cambiar. Revisar fuentes oficiales periódicamente.
